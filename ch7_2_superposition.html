หลักการซ้อนทับ: ความถี่เดียวกันและความถี่ต่างกัน Superposition — add phasors at one frequency, add time functions across frequencies

Superposition: same and different frequencies Add phasors at one frequency, add time functions across frequencies

หลักการซ้อนทับของบทที่ 5 ยังใช้ได้ เพราะวงจรที่มี R, L, C ยังเป็นวงจรเชิงเส้น: ฆ่าแหล่งจ่ายทุกตัวยกเว้นตัวเดียว (แหล่งจ่ายแรงดัน → ลัดวงจร แหล่งจ่ายกระแส → เปิดวงจร) หาผลย่อย แล้วรวมกัน ผู้สอนติดดาวหัวข้อนี้ไว้ในห้อง เพราะมีสองกรณีที่ต้องแยกให้ออก ถ้าแหล่งจ่ายทุกตัวมีความถี่เดียวกัน (Ex 3) ผลย่อยเป็นเฟเซอร์ที่ ω เดียวกันและบวกกันได้ ถ้าความถี่ต่างกัน (Ex 4) อิมพีแดนซ์ของ L และ C ไม่เท่ากันในแต่ละความถี่ ต้องคิดทีละความถี่ แล้วบวกกันในรูปฟังก์ชันเวลาเท่านั้น

Superposition from chapter 5 still works, because a circuit of R, L and C is still linear: kill every source but one (voltage source → short, current source → open), find the partial response, then add. The teacher starred this topic in class, because there are two cases to tell apart. If all sources share one frequency (Ex 3), the partial responses are phasors at the same ω and simply add. If the frequencies differ (Ex 4), L and C have different impedances at each frequency, so each frequency is solved separately and the results add only as time functions.

$$ \begin{aligned} \omega_1 = \omega_2:&\quad \mathbf{V} = \mathbf{V}' + \mathbf{V}'' \\ \omega_1 \ne \omega_2:&\quad v(t) = v'(t) + v''(t) \end{aligned} $$

ประเด็นสำคัญของหน้านี้

  • ฆ่าแหล่งจ่ายแบบเดิม: แหล่งจ่ายแรงดันเป็นลัดวงจร แหล่งจ่ายกระแสเป็นวงจรเปิด แล้วหาผลย่อยทีละตัว
  • ความถี่เดียวกัน: \(\mathbf{V}_1 = \mathbf{V}_1' + \mathbf{V}_1''\) เป็นการบวกจำนวนเชิงซ้อน ใน Ex 3 ได้ \(1.062\angle 23.27^\circ\) V เท่ากับคำตอบของ Ex 1 พอดี
  • ความถี่ต่างกัน: \(Z_L = j\omega L\) ที่ 200 rad/s คือ j1 Ω แต่ที่ 100 rad/s คือ j0.5 Ω จึงไม่มีวงจรเฟเซอร์วงเดียวที่ใช้ได้กับทุกแหล่งจ่าย ซ้อนทับเป็นวิธีเดียว
  • ห้ามบวกเฟเซอร์ต่างความถี่ (เช่น 2∠180° + 0.5∠180°) ต้องแปลงเป็นฟังก์ชันเวลาก่อน แล้วบวก \(v_L = 2\sin(200t + 180^\circ) + 0.5\sin(100t + 180^\circ)\) V ซึ่งไม่ใช่คลื่นไซน์
  • ใน Ex 4 แหล่งจ่ายแรงดันที่อนุกรมกับแหล่งจ่ายกระแสไม่มีผลต่อ \(v_L\) เพราะเมื่อมันทำงานตัวเดียว ไม่มีทางให้กระแสไหลครบวง

Key points of this page

  • Kill sources as before: voltage sources become shorts, current sources open circuits; then find the partial responses one at a time.
  • Same frequency: \(\mathbf{V}_1 = \mathbf{V}_1' + \mathbf{V}_1''\) is complex addition. Ex 3 gives \(1.062\angle 23.27^\circ\) V, exactly the answer of Ex 1.
  • Different frequencies: \(Z_L = j\omega L\) is j1 Ω at 200 rad/s but j0.5 Ω at 100 rad/s, so no single phasor circuit fits every source. Superposition is the only way.
  • Never add phasors of different frequencies (such as 2∠180° + 0.5∠180°); convert to time functions first, then add: \(v_L = 2\sin(200t + 180^\circ) + 0.5\sin(100t + 180^\circ)\) V, which is not a sine wave.
  • In Ex 4, the voltage source in series with the current sources has no effect on \(v_L\): alone, it finds no closed path for a current.
