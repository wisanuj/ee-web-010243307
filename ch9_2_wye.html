The Y–Y connection Three single-phase circuits sharing one return lead

โหลดต่อแบบวายที่สมดุล (balanced Y-connected load) มีอิมพีแดนซ์ \(Z_p\) เท่ากันทุกเฟส ต่อระหว่างสายกับจุดนิวทรัล N · ทุกค่าเป็นค่ายังผล · สไลด์บทที่ 9 หน้า 11–14 · Hayt §12.3A balanced Y-connected load has the same impedance \(Z_p\) in every phase, each between a line and the neutral point N · all values are rms · chapter 9 slides, pp. 11–14 · Hayt §12.3
$$ \mathbf{I}_{aA} = \frac{\mathbf{V}_{an}}{Z_p} \qquad \mathbf{I}_{bB} = \mathbf{I}_{aA}\angle{-120^\circ} \qquad \mathbf{I}_{cC} = \mathbf{I}_{aA}\angle{-240^\circ} \qquad \mathbf{I}_{Nn} = \mathbf{I}_{aA} + \mathbf{I}_{bB} + \mathbf{I}_{cC} = 0 \qquad P = 3V_pI_L\cos\theta $$

เมื่อต่อโหลดวายที่สมดุลเข้ากับแหล่งจ่ายวาย แต่ละเฟสคือวงจรเฟสเดียวที่มีแหล่งจ่าย \(\mathbf{V}_{an}\) กับอิมพีแดนซ์ \(Z_p\) สามวงใช้สายกลับร่วมกันหนึ่งเส้น (สายนิวทรัล) สไลด์หน้า 12 สรุปว่ากระแสสายสามเส้นมีขนาดเท่ากันและห่างกัน 120° จึงรวมกันได้ศูนย์ สายนิวทรัลไม่มีกระแสเลย ถอดออกได้โดยไม่มีอะไรเปลี่ยน (ระบบสามสาย) เราจึงคิดเพียงเฟสเดียวแล้วเลื่อนมุมไป ±120° ได้อีกสองเฟส Hayt เรียกว่าการวิเคราะห์ทีละเฟส (per-phase analysis) ในโหลดวาย กระแสเฟสกับกระแสสายคือกระแสเดียวกัน ส่วนแรงดันสายโตกว่าแรงดันเฟส \(\sqrt3\) เท่า

When a balanced Y load is connected to a Y source, each phase is a single-phase circuit, a source \(\mathbf{V}_{an}\) and an impedance \(Z_p\); the three circuits share one return lead (the neutral). Slide p. 12 concludes that the three line currents have equal size, 120° apart, so they add to zero and the neutral carries no current at all; it can be removed without changing anything (a three-wire system). We therefore work out one phase only and shift the angle by ±120° for the other two: Hayt calls this per-phase analysis. In a Y load the phase current and the line current are the same current, while the line voltage is \(\sqrt3\) times the phase voltage.

ประเด็นสำคัญของหน้านี้

  • วิเคราะห์ทีละเฟส: \(\mathbf{I}_{aA} = \mathbf{V}_{an}/Z_p\) แล้ว \(\mathbf{I}_{bB}\), \(\mathbf{I}_{cC}\) ได้จากการเลื่อนมุม −120° และ −240° (ลำดับบวก) ไม่ต้องแก้สมการทั้งวงจร
  • โหลดวาย: กระแสเฟส = กระแสสาย (\(\mathbf{I}_{AN} = \mathbf{I}_{aA}\)) และแรงดันเฟสของโหลด = \(V_p\), แรงดันสาย = \(\sqrt3V_p\)
  • โหลดสมดุล: \(\mathbf{I}_{Nn} = 0\) จะต่อหรือถอดสายนิวทรัลก็ได้ผลเท่าเดิม แต่โหลดไม่สมดุลจะมีกระแสในนิวทรัล และถ้าถอดนิวทรัล แรงดันของจุด N จะเลื่อนไป
  • กำลังรวม \(P = 3V_pI_L\cos\theta\) โดย \(\theta\) คือมุมของ \(Z_p\) และกำลังรวมขณะใด ๆ ของระบบสามเฟสสมดุลคงที่ (Hayt) มอเตอร์สามเฟสจึงได้แรงบิดเรียบ
  • รู้ \(P\), PF และ \(V_L\) ก็หากระแสได้: \(V_p = V_L/\sqrt3\), \(P_p = P/3\), \(I_L = P_p/(V_p\cos\theta)\), \(|Z_p| = V_p/I_L\) (Ex 2)

Key points of this page

  • Per-phase analysis: \(\mathbf{I}_{aA} = \mathbf{V}_{an}/Z_p\), and \(\mathbf{I}_{bB}\), \(\mathbf{I}_{cC}\) follow by shifting the angle by −120° and −240° (positive sequence); no need to solve the whole circuit.
  • Y load: phase current = line current (\(\mathbf{I}_{AN} = \mathbf{I}_{aA}\)); the load's phase voltage is \(V_p\) and the line voltage \(\sqrt3V_p\).
  • Balanced load: \(\mathbf{I}_{Nn} = 0\), so connecting or removing the neutral changes nothing. An unbalanced load drives current in the neutral, and without the neutral the voltage of point N shifts.
  • Total power \(P = 3V_pI_L\cos\theta\) with \(\theta\) the angle of \(Z_p\), and the total instantaneous power of a balanced three-phase system is constant (Hayt), so a three-phase motor gets a smooth torque.
  • From \(P\), PF and \(V_L\): \(V_p = V_L/\sqrt3\), \(P_p = P/3\), \(I_L = P_p/(V_p\cos\theta)\), \(|Z_p| = V_p/I_L\) (Ex 2).

      Try this 1 — the neutral

      1. In Part 1 with the balanced load, connect or remove the neutral: every value stays the same and the neutral dots do not move.
      2. Choose "Z_C = 50∠60° Ω" and connect the neutral: a current \(\mathbf{I}_{Nn}\) returns through it, but every phase still has 200 V.

      Try this 3 — rms or peak?

      1. In Part 3, \(I_L = 2.89\) A takes 300 V as an rms value, as Hayt's footnote and the definition of \(V_p\) on slide p. 7 say.
